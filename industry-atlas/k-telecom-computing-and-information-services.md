# K — Telecom, computing and information services

[All sectors](index.md) · [Cross-sector ecosystems](ecosystems.md) · [Source PDF](Global_Industry_Business_Software_AI_Atlas_2026.pdf#page=86)

**Coverage:** 3 divisions / 8 groups / 9 classes / 33 business examples. Source pp. 86–88.

## Scope

This is the technical service and infrastructure layer: telecom, custom development, IT services, hosting and search. A provider selling AI capacity does not necessarily use advanced AI in its own operations.

**Evidence scope in the atlas:** GSMA and developer evidence support selected workflows. Respondent and operator-level findings are not interchangeable with firm adoption rates. [S19](references.md#s19) [S20](references.md#s20) [S06](references.md#s06) [S30](references.md#s30)

The D/A ranges and class-level AI examples below are analyst estimates or candidate applications. They are not measured adoption rates or proof of buyer demand.

## Activity catalogue

<a id="division-61"></a>
### Division 61 — Telecommunications

#### Group 611 — Wired, wireless and satellite telecom

<a id="class-6110"></a>
##### 6110 — Wired, wireless and satellite telecom

**Maturity estimate:** D3-D4 / A1-A3; confidence: medium.

- **Businesses:** fixed-line operators; mobile network operators; internet access providers; satellite telecom operators.
- **Software:** Network operations, customer billing, service provisioning, support and security systems.
- **AI applications / candidates:** Network anomalies, demand prediction and customer assistance.
- **Adoption context:** AI builds on extensive network data; deployment differs by operator and legacy estate.
- **Watchpoint:** Protect critical communications and subscriber privacy.

#### Group 612 — Telecom reselling and intermediation

<a id="class-6120"></a>
##### 6120 — Telecom reselling and intermediation

**Maturity estimate:** D2-D3 / A0-A2; confidence: low.

- **Businesses:** virtual mobile operators; telecom resellers; telecom service brokers.
- **Software:** Subscriber billing, provisioning, customer service, partner integration and sales systems.
- **AI applications / candidates:** Churn analysis and customer enquiry support.
- **Adoption context:** AI is usually embedded in customer or network-support products rather than owned models.
- **Watchpoint:** Confirm service entitlement and customer consent.

#### Group 619 — Other telecommunications

##### 6190 — Other telecommunications

- **Businesses:** specialist telecom service providers; telecom access service businesses; other telecom operators.
- **Software:** Subscriber billing, provisioning, customer service, partner integration and sales systems.
- **AI applications / candidates:** Service triage and network-log interpretation.
- **Adoption context:** AI is usually embedded in customer or network-support products rather than owned models.
- **Watchpoint:** Confirm service entitlement and customer consent.

<a id="division-62"></a>
### Division 62 — Programming, IT consultancy and related services

#### Group 621 — Computer programming

<a id="class-6211"></a>
##### 6211 — Video-game and game-tool development

**Maturity estimate:** D3-D4 / A1-A3; confidence: medium.

- **Businesses:** game development studios; contract game developers; game-engine tool developers.
- **Software:** Game engines, source control, asset pipelines, testing, build systems and analytics.
- **AI applications / candidates:** Code assistance, asset workflows and automated testing.
- **Adoption context:** Coding and art tools offer AI assistance; adoption depends on studio policies and rights.
- **Watchpoint:** Generated assets and code need quality and license review.

<a id="class-6219"></a>
##### 6219 — Other computer programming

**Maturity estimate:** D3-D4 / A1-A3; confidence: medium.

- **Businesses:** custom software developers; website developers; mobile-app developers; AI application engineering firms.
- **Software:** Source control, code editors, testing, issue tracking, cloud deployment and documentation.
- **AI applications / candidates:** Code generation, tests, debugging and documentation.
- **Adoption context:** Developer AI use can be high without fully autonomous project delivery.
- **Watchpoint:** Test outputs and protect source code and credentials.

#### Group 622 — IT consultancy and computer facilities management

<a id="class-6220"></a>
##### 6220 — IT consultancy and computer facilities management

**Maturity estimate:** D3-D4 / A1-A3; confidence: medium.

- **Businesses:** IT consultancies; managed IT providers; enterprise systems integrators; computer facilities managers.
- **Software:** Service desks, monitoring, remote management, configuration records, projects and security tools.
- **AI applications / candidates:** Incident triage, knowledge search and code assistance.
- **Adoption context:** AI assists repetitive support and analysis; privileged actions need controls.
- **Watchpoint:** Use least privilege, audit logs and approval gates.

#### Group 629 — Other IT and computer services

<a id="class-6290"></a>
##### 6290 — Other IT and computer services

**Maturity estimate:** D3-D4 / A1-A3; confidence: medium.

- **Businesses:** disaster-recovery services; computer setup services; data-recovery firms; other IT support providers.
- **Software:** Service desks, monitoring, remote management, configuration records, projects and security tools.
- **AI applications / candidates:** Service-ticket triage and technical knowledge search.
- **Adoption context:** AI assists repetitive support and analysis; privileged actions need controls.
- **Watchpoint:** Use least privilege, audit logs and approval gates.

<a id="division-63"></a>
### Division 63 — Computing infrastructure and information services

#### Group 631 — Computing infrastructure, data processing and hosting

<a id="class-6310"></a>
##### 6310 — Computing infrastructure, data processing and hosting

**Maturity estimate:** D4 / A1-A4; confidence: medium.

- **Businesses:** cloud infrastructure providers; data centres; web hosting firms; data-processing bureaus.
- **Software:** Compute orchestration, monitoring, billing, security, data platforms and service operations.
- **AI applications / candidates:** Capacity planning, security alerts and workload operations.
- **Adoption context:** AI infrastructure is core for some providers; ordinary hosting may use little operational AI.
- **Watchpoint:** Track cost, tenant isolation and data access.

#### Group 639 — Web search portals and other information services

<a id="class-6390"></a>
##### 6390 — Web search portals and other information services

**Maturity estimate:** D3-D4 / A1-A4; confidence: medium.

- **Businesses:** search engines; information retrieval services; business information providers; information portals.
- **Software:** Search indexes, databases, content pipelines, APIs, analytics and subscriptions.
- **AI applications / candidates:** Information retrieval, summarization and entity matching.
- **Adoption context:** AI can be central to retrieval and synthesis; traditional information services vary.
- **Watchpoint:** Show provenance and avoid unsupported summaries.

## Focused business subtypes

These 72 PDF appendix profiles are editorial refinements of a parent class, not extra official classes. All are labeled low confidence in the source.

<a id="subtype-11"></a>
### 11 — Custom AI application developers

**Parent:** [6219](#class-6219) · D3-D4 / A2-A3 / Estimate confidence: low · source p. 133.

- **Software:** Client code, model integration, retrieval systems, testing, deployment and documentation.
- **AI applications / candidates:** Coding assistance and building client-specific AI workflows.
- **Boundary / watchpoint:** Use separate controls for the developer's own AI and the delivered product.

<a id="subtype-12"></a>
### 12 — Web and mobile application agencies

**Parent:** [6219](#class-6219) · D3-D4 / A1-A3 / Estimate confidence: low · source p. 133.

- **Software:** Design, source control, build pipelines, testing, deployment and client project management.
- **AI applications / candidates:** Code generation, tests, content drafts and debugging.
- **Boundary / watchpoint:** Human review is needed for security, accessibility and acceptance criteria.

<a id="subtype-13"></a>
### 13 — Business automation and integration developers

**Parent:** [6219](#class-6219) · D3-D4 / A1-A3 / Estimate confidence: low · source p. 133.

- **Software:** APIs, workflow engines, connectors, event logs, testing and deployment tools.
- **AI applications / candidates:** Document interpretation and bounded agentic workflow steps.
- **Boundary / watchpoint:** Conventional integration scripts and robotic process automation are not necessarily AI.

<a id="subtype-14"></a>
### 14 — Cloud and infrastructure managed-service providers

**Parent:** [6220](#class-6220) · D3-D4 / A1-A3 / Estimate confidence: low · source p. 134.

- **Software:** Monitoring, service desks, configuration, security, billing and customer access controls.
- **AI applications / candidates:** Incident summarization and operational knowledge retrieval.
- **Boundary / watchpoint:** Do not allow unapproved infrastructure changes.

<a id="subtype-15"></a>
### 15 — Cybersecurity consulting and managed IT security

**Parent:** [6220](#class-6220) · D3-D4 / A1-A3 / Estimate confidence: low · source p. 134.

- **Software:** Security monitoring, incident response, customer systems and case records.
- **AI applications / candidates:** Detection support, alert triage and investigation assistance.
- **Boundary / watchpoint:** Classification follows the actual IT service; non-IT guarding belongs elsewhere.

<a id="subtype-16"></a>
### 16 — Cloud infrastructure and compute providers

**Parent:** [6310](#class-6310) · D4 / A1-A3 / Estimate confidence: low · source p. 134.

- **Software:** Compute, storage, networking, orchestration, metering, security and customer operations.
- **AI applications / candidates:** Capacity forecasts and infrastructure anomaly detection.
- **Boundary / watchpoint:** Providing compute for AI does not prove AI runs the provider's own operations.

<a id="subtype-17"></a>
### 17 — Data-centre operators and colocation providers

**Parent:** [6310](#class-6310) · D3-D4 / A0-A2 / Estimate confidence: low · source p. 134.

- **Software:** Power and cooling management, racks, access controls, maintenance and customer billing.
- **AI applications / candidates:** Cooling-demand forecasts and equipment failure alerts.
- **Boundary / watchpoint:** Digital building controls alone are not AI.

<a id="subtype-18"></a>
### 18 — Hosting and data-processing bureaus

**Parent:** [6310](#class-6310) · D3-D4 / A0-A2 / Estimate confidence: low · source p. 134.

- **Software:** Hosting platforms, job processing, data storage, customer support and billing.
- **AI applications / candidates:** Document processing and service-ticket assistance.
- **Boundary / watchpoint:** Software publishing and hosting are different principal activities.

<a id="subtype-19"></a>
### 19 — Search and information-discovery businesses

**Parent:** [6390](#class-6390) · D4 / A2-A4 / Estimate confidence: low · source p. 134.

- **Software:** Indexing, retrieval, crawling, databases, information rights and query serving.
- **AI applications / candidates:** Semantic retrieval and source-linked answer generation.
- **Boundary / watchpoint:** Generated answers require provenance and evaluation.
