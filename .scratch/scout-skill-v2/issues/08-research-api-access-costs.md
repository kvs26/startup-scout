## Question

Across the researched website and creator sources, which official APIs, feeds or exports can scout v2 actually use, what do they retrieve, and what do access and repeated use cost?

The user requests adding available APIs and is open to low-cost paid services. Compile a complete inventory across the existing research set, grouping sources without a verified public API instead of inventing endpoints. Include existing configured supporting retrieval tools when relevant. Verify primary documentation for authentication, approval/licensing, coverage, quota/pricing and useful fallback; distinguish official APIs from third-party scraping services and API documentation from a successful call. Do not create accounts, install integrations or subscribe during this research.

Estimate a clearly hypothetical small scouting workload only where official pricing supports calculation; flag per-call versus subscription, renewals, overages and unknown quotes. Avoid assuming that a cheap metadata endpoint retrieves transcripts or full posts. Recommend a staged connection plan without excluding API options merely because free web pages exist. Use web/browser and user-supplied screenshots/pasted text as explicit fallback proposals. The user confirmed an initial aggregate planning cap of ₹1,000/month on 2026-10-28; taxes, exchange-rate uncertainty and renewal/overage exposure must fit the comparison. No subscription has been chosen.

Save one cited artifact, capture it on a disposable research branch, and record a concise factual resolution. Cost and source adoption remain with the user.

## Answer

Resolved 2026-10-28 by Codex / API-access-research. [API, feed and export access for scout version 2](../api-access-research.md) inventories all 28 website entries (12 with documented structured routes, 16 without a verified general discovery API), YouTube/Instagram and existing supporting tools. The user supplied a combined initial paid-research cap of ₹1,000/month during this research; source/account adoption remains with the user.

Practical first tests: HN, existing Tavily allowance, YouTube metadata and SaaSHub after checking account terms. Tavily publishes 1,000 included credits and $0.008 PAYG per additional credit; a clearly hypothetical capped workload and FX/fee buffer are shown. Product Hunt needs business-use clearance, BetaList is case-by-case, Google Trends is restricted alpha, and company databases need quotes. Inc42 pricing FAQ explicitly denies a public API and offers CSV (not direct Excel), with conflicting plan allowances; ₹1,499 + GST already exceeds cap. Exploding Topics minimum advertised API package plus prerequisite totals $1,249/month.

Limits: documentation checks do not establish connected APIs. No authenticated calls, secret inspection, subscriptions, installations or approvals were performed. YouTube metadata cannot supply arbitrary caption downloads; edit permission is required for that API. Instagram professional-account routes exist, but exact scoped discovery entitlement/quotas remain to test. Browser and user screenshots/paste/export are supported fallbacks with provenance and source-specific restrictions. Provider prices/quotas can change.
