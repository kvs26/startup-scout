# Free and low-cost access across the selected scout sources

Checked **2026-10-29**. Supports [Audit free and low-cost access across the selected source portfolio](issues/11-audit-selected-source-access.md) and the resolved [source-selection decision](issues/04-select-source-portfolio.md#answer).

## Finding and scope

The starting portfolio can be researched through public pages, original creator material and included/free APIs without buying a source subscription. The most useful structured additions are HN, YouTube metadata, GitHub public issues and Stack Exchange questions/answers. SaaSHub is promising but its published documentation does not establish a numeric allowance or price. Existing Tavily free credits can support retrieval; modest metered usage is a possible later purchase, not an activated service.

This reconciles every named selected source, the ten starting creator candidates, the existing catalog's community/review/context examples, and conditional sources from the earlier research. Future relevant communities, local businesses and industry bodies are dynamic groups: their exact members depend on the chosen business areas. This is not a claim to have enumerated every possible site or private API.

**Evidence states:** **fresh docs** means primary documentation or public page inspected on October 29; **prior check** preserves the October 28 [API inventory](api-access-research.md), [coverage research](source-coverage-research.md), [creator research](creator-source-research.md), or October 3/17 [catalog checks](../../docs/startup-skills/source-catalog.md). A documented route is **not connected or tested** unless a historical test is explicitly identified. No authenticated calls, signup, secret inspection, subscriptions, account changes or new installations occurred here. “No verified API” means none established in these checks, not proof no private arrangement exists. Public reading is not permission for unrestricted extraction or republication.

The sole recurring paid-API planning cap is **₹1,000/month across all providers combined**. No foreign exchange rate is assumed below. Dollar prices retain their billing currency; actual rupee totals require checkout conversion, taxes/fees, renewal terms and remaining budget. A cheap unit price is insufficient if minimum purchase or uncapped usage can exceed the budget.

## Creator pool: one platform route serves many creators

**YouTube first.** Fresh [Data API quota documentation](https://developers.google.com/youtube/v3/determine_quota_cost) lists 100 search calls/day separately from the ordinary 10,000-unit/day pool; channel/playlist/video lists ordinarily cost one unit. Use uploads playlists for known channels. API project/credentials and actual project quota need verification. The documented route has no per-call tariff established here and retrieves metadata/comments, not arbitrary spoken transcripts.

Fresh [caption-download documentation](https://developers.google.com/youtube/v3/docs/captions/download) requires OAuth and permission to edit the video. It cannot download arbitrary creators' captions just because the scout has an API key. [YouTube transcript UI](https://support.google.com/youtube/answer/15930243) is the free documented route when captions exist; creator articles/show notes and user-provided transcripts are fallbacks. No transcript vendor was bought or verified, and no full-video/transcript success is claimed here. Preserve original URL, date, timestamps and omissions; ask for frames where visual evidence matters.

**Instagram supplementary.** The prior [Meta official collection](https://www.postman.com/meta/instagram/collection/6yqw8pt/instagram-api) documents authenticated professional-account APIs. Public-post/browser access may work; arbitrary reels, keyword discovery and spoken transcripts are not established API capabilities. Current scoped approval/quota/price remains unknown, and no account was tested. Prefer the creator's corresponding YouTube original when available; count a cross-post once. Lack of Instagram access is not a campaign failure.

## Supporting retrieval and cheap paid choices

[Tavily pricing](https://docs.tavily.com/documentation/api-credits), freshly checked: **1,000 free credits/month**, no card required; PAYG **$0.008/credit**; smallest monthly plan **$30 for 4,000 credits**. Basic search uses one credit; advanced two; five successful basic URL extractions use one. Crawl adds map and extraction consumption. **500 paid credits = $4 before conversion/tax**, a plausible small top-up only after checking remaining aggregate budget and billing controls. No paid minimum/top-up checkout or hard spending cap was verified; do not enable uncapped PAYG. A fixed $30 plan is not recommended for this initial budget.

[SETUP.md](../../SETUP.md) records Tavily authentication and configured VS Code execution on October 10, including a partial crawl and unconfirmed PAYG-off status. This is historical configuration, not current balance/client verification. Existing built-in web/browser tools provide another retrieval path; this audit makes no claim about their host-app billing or universal site access. Hunter/Apollo are existing contact-research aids; their previously recorded plan limits do not help retrieve all these source texts, so no upgrade is proposed here.

No selected source's quote-only API can be called cheap without a real offer. No creator course or premium database is needed to begin. User-provided transcripts, screenshots, copied passages and authorized exports carry no new source-API purchase, but must preserve source links and what was actually supplied.
